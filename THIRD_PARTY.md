# Third-party code in this distribution

a3d is Apache-2.0 (see [`LICENSE`](LICENSE) and [`NOTICE`](NOTICE)) and every
file it owns carries an `SPDX-License-Identifier`. This file lists what is
**not** covered by that grant, so the boundary is written down rather than
inferred from which files happen to lack a header.

**The library is one item long.** `include/`, `backends/`, `loaders/` and
`viewer/` contain no third-party code and depend on nothing outside the C++17
standard library — with the single exception below, which is data rather than
code and which you only link if you include it.

This file covers **the library only**. The example projects are not part of
that boundary: they carry vendor board drivers whose licence headers are in
their own sources, and they are built separately from anything a3d ships as a
component.

## The bitmap fonts — DejaVu Sans Mono

`backends/soft/a3d_font_8x14.h`, `a3d_font_12x21.h` and `a3d_font_20x35.h` are
generated by `tools/gen_font.py`, which rasterizes glyph outlines into 1-bit
bitmaps. The tables are therefore a **derivative of DejaVu Sans Mono**, and they
carry its licence into anything that links them.

    Bitstream Vera Fonts Copyright (c) 2003 by Bitstream, Inc.
    Arev Fonts Copyright (c) 2006 by Tavmjong Bah
    DejaVu changes are in the public domain.

The full text is in [`docs/LICENSE_DEJAVU.txt`](docs/LICENSE_DEJAVU.txt) and is
reproduced with this distribution because that licence requires it. It permits
redistribution, modification and sale; the one condition that bites a derived
bitmap is the naming rule, which is why none of these tables is called
`Bitstream` or `Vera` anything.

**The built-in 5x7 font is not affected.** `backends/soft/a3d_soft_text.h` was
authored by hand here, is derived from no face, and is Apache-2.0 like the rest
of the library — so a program that draws text with only that one carries no font
licence at all.

See [`docs/FONTS.md`](docs/FONTS.md) for how to generate your own, and for why
the tool refuses to rasterize your operating system's fonts.
